# FastFps

È um projeto público open-source que visa areas de renderização de chunk é principalmente o OpenGL melhorando significamente a renderização de blocos ou chunks melhorando o fps é deixando ele estavel, em muitas das vezes em pcs mais fracos tem um ganho significamente maior em menos quedas de fps

## Installation

1. Baixe o mod `.jar` vá na pagina de [Releases](https://github.com/lidanthedev/BackportedCompletions/releases) baixe la.
2. Coloque o arquivo `.jar` na pasta `mods` para funcionar.
3. Apenas compativel com a versão 1.9 + Forge(Em breve mais versões.)

## Features

Em breve adcionaremos mais recursos é melhor tratamento de chunks ainda não carregadas ou travamento na hora de renderizar um terreno enorme.
